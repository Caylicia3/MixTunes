## 修改范围与设置

- Windows 和 Android 共用背景设置，增加「背景遮罩强度」0～100% 滑块。0% 为透明遮罩，100% 为完全不透明，拖动立即生效并保存，无需保存按钮。
- 浅色遮罩为白色，深色为 RGB(32,33,35)。分别使用 `mixtunes-background-mask-light`、`mixtunes-background-mask-dark` 两个本机键；未设置时保持旧版 88%／90%，不主动写入新默认值。
- 图片不透明度、背景模糊度和遮罩各自独立；更改遮罩不改背景模式、图片、裁剪参数、歌曲、队列或播放状态。
- 主界面与裁剪「预览背景效果」共用相同的分主题 CSS 参数，切主题后滑块和遮罩同步更新。未勾选效果预览时仍保留原始裁剪预览行为。
- 低遮罩可能影响文字可读性，界面提供提示；装饰层仍不接收点击，控件可操作。
- Android Web runtime 和共享 CSS 已重新生成并核对 APK 内哈希。原生功能源码、包名和用户数据格式不变，versionCode 从 13 增至 14。
