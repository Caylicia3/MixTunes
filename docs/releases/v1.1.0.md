# MixTunes 1.1.0 候选发布说明

状态：发布准备阶段，尚未合并 main、创建 Tag 或发布 Release；候选包仍需用户最终验收。

本版本基于上游 1.0.0（`5c7d748`），整合个人 Fork 已验收开发提交至 `9db3afd`，保留全部原始提交。整合历史对应 PR #1、#2、#3、#4、#10、#11、#12、#15、#20、#22。歌单读失败保护单独记录于 [Issue #23](https://github.com/Caylicia3/MixTunes/issues/23)。

## 改动

- 两端一键定位正在播放：返回实际来源歌单，清除关键词和平台筛选，滚动突出歌曲；不重启播放，不改进度、播放状态或队列。
- 区分歌单筛选与在线搜索；添加歌曲显示明确成功／失败／同名同作者反馈，已存在歌曲按真实歌单归属显示勾选，仍可添加到其他歌单。
- Windows 关闭到托盘继续播放，双击恢复，菜单显式退出；托盘不可用时正常退出。
- 当前封面背景、自定义本地背景、拖动／缩放裁剪、图片不透明度、按模式记忆的模糊度与实时预览。
- 双端原创「折带播放」图标及统一 SVG 资源生成流程。
- 15／30／60 分钟和 1～240 分钟睡眠定时器，到期只暂停；真正退出后不恢复。
- Windows 歌单读失败时中止启动并禁止保存，不以空歌单覆盖原文件。

## 安装与升级

发布入口：[个人 Fork Releases](https://github.com/Caylicia3/MixTunes/releases)。

| 平台 | 文件 | 使用方式 |
| --- | --- | --- |
| Windows 10/11 x64 | `MixTunes-1.1.0-win-x64.zip` | 完整解压到新目录，运行 `MixTunes.exe`；不能只复制 EXE |
| Android 8.0+ | `MixTunes-Android-1.1.0.apk` | versionCode 13；同 Fork 签名旧测试版可覆盖，最终真机升级仍待验收 |

升级前退出旧应用并保留旧包。Windows 数据仍在 `%APPDATA%\MixLink`，切换程序目录不迁移数据；不要删除此目录。Windows 未做代码签名，不修改系统安全策略或图标缓存。

Android 包名保持 `local.mixtunes.mobile`，使用已有 Fork 本地 debug 证书，SHA-256：

`521aecc240daa9ce9f5a526a46bf6a82de72b6b1e03122a1944c1990da25a7ae`

它与上游 1.0.0 的签名不同，不能直接覆盖上游应用。不要为安装自动卸载或清数据。歌单 JSON 导出不含登录会话、自定义图片及所有界面设置，不能视作完整设备备份。

## 数据与边界

歌单保持 schemaVersion 2；Windows 数据路径、Android 包名、WebView 地址及设置键保持不变。本地背景仍为私有 `custom-background.json` version 1，保留 `crop.x/y/zoom`；模式、不透明度、封面／自定义模糊度各自保存在本机，不随歌单导出。睡眠定时器是进程内状态，不写入备份或设置，升级退出后需重新设置。

若 Windows 提示歌单读取失败，应用将停止启动并保留原文件。先完整备份数据目录，再检查 `library.json` 内容／访问权限；本版本不提供自动恢复，也不应通过清空文件来掩盖错误。

## 已知限制及未纳入事项

- 最近播放历史（任务 G / #14）已取消；平台搜索排序（#21）未实现。
- Bilibili 音频切换视频可能不继承进度（#16），本轮未修复。
- 会员、地区、登录和接口风控仍由原平台决定；Android 原有 QQ／网易网页备用播放限制保留。
- 系统结束 Android 进程后不恢复播放或定时器；深度休眠下调度受系统限制，恢复时补结算，不承诺精确闹钟。
- 未产出 portable EXE 安装器，本轮交付 Windows ZIP。
- 历史功能人工验收由用户确认完成；正式候选包仍需再次验收。自动化、打包检查和真机测试分别记录，详见测试报告。

## 可复现构建

Node.js >=22.12；锁定 Electron 44.8.0、electron-builder 26.15.3。`app` 中执行 `npm ci`、`npm test`、`npm run dist:zip`。如已有 Electron 运行时，按项目配置准备 `app/node_modules/electron/dist`；本机候选构建使用项目内缓存，不把工具路径打入应用。

Android 需要 JDK 17、SDK Platform 35、Build Tools 35.0.0。先在根目录运行 `node android/build-web.cjs`，再执行：

```powershell
& ./android/native/build.ps1 -SdkDirectory $env:ANDROID_HOME -VersionName 1.1.0 -VersionCode 13 -RequireExistingKey
& ./android/native/verify-build.ps1 -SdkDirectory $env:ANDROID_HOME -ExpectedVersion 1.1.0 -ExpectedVersionCode 13 -ExpectedCertificateSha256 '521aecc240daa9ce9f5a526a46bf6a82de72b6b1e03122a1944c1990da25a7ae'
```

发布构建必须复用现有私有密钥；缺失就停止，禁止生成替代密钥。签名目录、构建缓存、账号及歌单均不提交或上传。
