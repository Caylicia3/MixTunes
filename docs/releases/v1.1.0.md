# MixTunes v1.1.0 发布说明

Windows / Android 最终安装包已于 2026-10-18 获用户确认通过双端人工验收，PR #24 已通过普通 Merge Commit 整合到个人 Fork main（`271a9e6c0c9416a0b0c6e989639cf865bd65b765`）。用户已明确批准以 v1.1.0 正式发布，并接受 Issue #16、#25 作为已知限制。Tag 指向最终 main，后续发布文档修正不改变应用源码或已验收二进制文件。

最终安装包包含背景遮罩补修，Android versionCode 14。包括遮罩在内的双端人工验收已通过；验收包路径、SHA-256、309 项 Node / 91 项 UI / 6 项打包集成测试和人工确认记录见 [最终测试报告](v1.1.0-mask-tests.md)。已知 Issue #16、#25 保留，整体验收结论不代表它们已修复。

本版本基于上游 1.0.0（`5c7d748`），整合个人 Fork 已验收开发提交至 `9db3afd`，保留全部原始提交。整合历史对应 PR #1、#2、#3、#4、#10、#11、#12、#15、#20、#22。歌单读失败保护单独记录于 [Issue #23](https://github.com/Caylicia3/MixTunes/issues/23)。

## 改动

- 两端一键定位正在播放：返回实际来源歌单，清除关键词和平台筛选，滚动突出歌曲；不重启播放，不改进度、播放状态或队列。
- 区分歌单筛选与在线搜索；添加歌曲显示明确成功／失败／同名同作者反馈，已存在歌曲按真实歌单归属显示勾选，仍可添加到其他歌单。
- Windows 关闭到托盘继续播放，双击恢复，菜单显式退出；托盘不可用时正常退出。
- 当前封面背景、自定义本地背景、拖动／缩放裁剪、图片不透明度、按模式记忆的模糊度与实时预览。新增 0～100% 背景遮罩强度，浅／深色主题分别记忆，默认 88%／90% 保持旧效果；降低遮罩可能影响文字可读性。勾选裁剪「预览背景效果」时使用相同遮罩。
- 双端原创「折带播放」图标及统一 SVG 资源生成流程。
- 15／30／60 分钟和 1～240 分钟睡眠定时器，到期只暂停；真正退出后不恢复。
- Windows 歌单读失败时中止启动并禁止保存，不以空歌单覆盖原文件。

## 数据与边界

歌单保持 schemaVersion 2；Windows 数据路径、Android 包名、WebView 地址及设置键保持不变。本地背景仍为私有 `custom-background.json` version 1，保留 `crop.x/y/zoom`；模式、不透明度、封面／自定义模糊度各自保存在本机，不随歌单导出。睡眠定时器是进程内状态，不写入备份或设置，升级退出后需重新设置。

若 Windows 提示歌单读取失败，应用将停止启动并保留原文件。先完整备份数据目录，再检查 `library.json` 内容／访问权限；本版本不提供自动恢复，也不应通过清空文件来掩盖错误。

## 已知限制及未纳入事项

- 最近播放历史（任务 G / #14）已取消；平台搜索排序（#21）未实现。
- Bilibili 音频切换视频可能不继承进度（#16），本轮未修复。
- QQ 音乐在线搜索失败（[#25](https://github.com/Caylicia3/MixTunes/issues/25)）尚未修复：Windows 已记录搜索失败，Android 相关异常的具体条件待核实；根因未确认，不能据此认定平台服务器故障，也不能保证当前包中已恢复。
- 会员、地区、登录和接口风控仍由原平台决定；Android 原有 QQ／网易网页备用播放限制保留。
- 系统结束 Android 进程后不恢复播放或定时器；深度休眠下调度受系统限制，恢复时补结算，不承诺精确闹钟。
- 未产出 portable EXE 安装器，本轮交付 Windows ZIP。
- 最终安装包人工验收由用户确认通过；自动化、打包检查和人工确认分别记录，详见测试报告。上述已知问题不因整体验收而视为已解决。

## 可复现构建

Node.js >=22.12；锁定 Electron 44.8.0、electron-builder 26.15.3。`app` 中执行 `npm ci`、`npm test`、`npm run dist:zip`。如已有 Electron 运行时，按项目配置准备 `app/node_modules/electron/dist`；验收构建使用项目内缓存，不把工具路径打入应用。本次发布复用已验收安装包，没有重新打包。

Android 需要 JDK 17、SDK Platform 35、Build Tools 35.0.0。先在根目录运行 `node android/build-web.cjs`，再执行：

```powershell
& ./android/native/build.ps1 -SdkDirectory $env:ANDROID_HOME -VersionName 1.1.0 -VersionCode 14 -RequireExistingKey
& ./android/native/verify-build.ps1 -SdkDirectory $env:ANDROID_HOME -ExpectedVersion 1.1.0 -ExpectedVersionCode 14 -ExpectedCertificateSha256 '521aecc240daa9ce9f5a526a46bf6a82de72b6b1e03122a1944c1990da25a7ae'
```

发布构建必须复用现有私有密钥；缺失就停止，禁止生成替代密钥。签名目录、构建缓存、账号及歌单均不提交或上传。
